# onlinesourdough

**Build better ways to work.**

Practical methods, templates and resources for digital business and everyday
work, including useful ways to work with AI. Created by
[Gustav Anderson](https://gustavonline.com).

The focus is learning and applying: guides, reusable frameworks, courses and
workshops that help you develop skills and improve how you work.

[Explore onlinesourdough](https://onlinesourdough.com) · [Explore The Onlinesourdough Method](https://github.com/onlinesourdough/AIOS-Plugin)

| Repository | What it helps you do |
| --- | --- |
