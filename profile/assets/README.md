# Brand assets

The source mark is the unchanged SVG served at
https://onlinesourdough.com/assets/onlinesourdough-mark-large-pixel-v3.svg,
also maintained in the website repository's `public/assets/` directory.

- `onlinesourdough-mark.svg`: the exact website source mark.
- `onlinesourdough-icon.png`: 512 × 512 PNG for the organisation avatar and plugin icons.
- `onlinesourdough-banner.png`: 1200 × 300 PNG for the organisation README.

- `banner.html`: editable banner source using the existing mark and brand colours.

The GitHub banner background matches the onlinesourdough tile in Gustav’s LinkedIn banner R11: `#E8D9C3`, confirmed on 17 October 2026. Supporting text retains the website’s brown `#2b1b12`.
The wordmark uses the website's Geist Pixel Square font; supporting text uses
Geist Sans. The local fonts retain their SIL Open Font License in
`fonts/LICENSE.txt`.

Use the common icon for plugins. Ordinary repository READMEs start with their
title and purpose, without decorative banners or repo-specific icons. The existing method banner assets use the same source mark and colours. Product screenshots,
useful diagrams and original third-party attribution remain with their owners.

Brand assets retain their owners' rights; a repository's software license does
not grant rights to its brand identity.
